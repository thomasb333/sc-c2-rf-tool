Getting Started

SC/C2 is a self-contained RF planning tool. No install, no server — open in any browser.

1RF Spectrum — 80+ radios by frequency. Hover for specs, click for programming reference. Filter by type.
2Radio Library — filter by brand, band, type. Select radios to assign to operators.
3User Loadouts — add operators, assign radios, view interop matrix. Roster saves automatically in this browser.
4Site Planner — select a radio to auto-load TX params, calculate FSPL and link budget.
5Codeplugs — drop a codeplug file to decode it in-browser. View channels, print field card, export JSON.

Site Planner — How It Works

Uses Free Space Path Loss (FSPL) — ideal model, no terrain. Good for max theoretical range and sanity checks.

FSPL = 20*log(d_km) + 20*log(f_MHz) + 32.44
EIRP = TX_Power + TX_Gain - Cable_Loss
Link_Budget = EIRP + RX_Gain - RX_Sensitivity

For terrain-corrected maps use Meshtastic Site Planner (ITM/Longley-Rice + SRTM). Site Planner tab shows config values for manual entry.
